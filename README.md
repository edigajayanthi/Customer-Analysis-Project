# Customer Analysis

## Objective

To analyze customer data and identify customer behavior, purchasing patterns, and business insights.

## Tools Used

* SQL
* Excel
* Power BI
  

## Key Analysis

* Customer behavior analysis
* Customer segmentation
* Sales and purchase analysis
* Data cleaning and transformation
* Dashboard creation

## Key Findings

* Identified important customer segments and purchasing patterns.
* Analyzed customer and sales performance to generate business insights.

## Project Outcome

Created an interactive Power BI dashboard to analyze customer behavior and business performance.
